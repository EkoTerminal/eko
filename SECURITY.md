# Reporting a security issue

This repository is a development snapshot. A public bug bounty is not established by this file.
Test only local copies, forks and data you control. Do not move funds, disrupt services, or share
credentials, private keys, personal data or another user's journal.

Use a private GitHub security advisory if the repository offers **Security → Report a vulnerability**.
Include the affected commit, impact and minimal local reproduction. If private reporting is unavailable,
open an issue asking for a private reporting channel without posting exploitation details or sensitive data.
